# React Native Secured Payment App

## Installation

### For Navigation

- npm install @react-navigation/native
- npm install react-native-safe-area-context
- npm install react-native-screens
- npm install @react-navigation/native-stack

#### For more details vist [React Native Navigation](https://reactnavigation.org/docs/getting-started/)

### For Icons

- npm install react-native-vector-icons
- npm install @types/react-native-vector-icons [if needed]

#### For more details and SETUP vist [React Native Navigation](https://github.com/oblador/react-native-vector-icons/tree/10.x)

### For AsyncStorage - used for short valiable storage

- npm install @react-native-async-storage/async-storage

### For Biometric - used for Biometric authentication (Face ID, Fingerprint, PIN/Pattern/Password)

- npm install react-native-biometrics

### Shorthand command

- npm i
